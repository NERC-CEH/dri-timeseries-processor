# 0.3.0

Refactor of the EddyPro flux processing path. Flux runs are no longer a separate CLI mode with their own
metadata source - they now flow through the standard pipeline as a derivation step, driven by the same
metadata API as every other dataset. A new `from-datasets` CLI mode requests datasets directly by ID and
works for both `TimeSeriesDataset` and `ObservationDataset` records.

### Breaking changes

- Removed the `eddypro` CLI subcommand. Flux processing is now triggered via `from-datasets` with the
  processed observation dataset ID (e.g. `--datasets flux-plynl-processed`).
- Removed the local EddyPro metadata source (`local_eddypro_metadata_source.py`) and the local flux
  metadata fixtures. Flux metadata is now resolved through the standard metadata API.
- Removed `FluxIO` (`io_backend/flux_io.py`). Raw `.dat` file staging is now handled by
  `S3DataRouter.stage_locally`.

### New features

- **`from-datasets` CLI mode**: request datasets directly by their metadata API ID. Accepts multiple
  dataset IDs in a single run and works for `TimeSeriesDataset` and `ObservationDataset` records without
  needing to know the dataset type in advance.
- **`EddyProRun` derivation method**: EddyPro now runs as a `DERIVATION` step inside the standard
  processing pipeline rather than as a bespoke CLI mode. It reads the staged raw files from its
  `LOAD_LOCAL_COPY` dependency, builds EddyPro config from templates, runs `eddypro_rp` and `eddypro_fcc`,
  and provides the output back into a `TimeFrame`.
- **`ObservationDataset` support**: `TimeSeriesContainer` and its mappers now work with both
  `TimeSeriesDataset` and `ObservationDataset` metadata objects.
- **Column ordering**: column mappings in the EddyPro processing metadata are ordered using `column_index`.

### Documentation

- Updated [`docs/flux_eddypro.md`](../docs/flux_eddypro.md), [`docs/cli_usage.md`](../docs/cli_usage.md),
  [`docs/architecture.md`](../docs/architecture.md), and `README.md` to describe the new flux flow and
  the `from-datasets` mode.

### Internal

- Moved local staging concerns into `S3DataRouter`, removing flux/EddyPro references from the pipeline
  itself.
- Refactored the CLI selection model: `SelectionOption` is replaced by typed `Selection` subclasses
  (`DimensionSelection`, `DatasetIdSelection`, `ListSitesSelection`).
- Updated `localstack-setup` with new bucket names.
- Pyright fixes and updated unit and end-to-end test fixtures.
