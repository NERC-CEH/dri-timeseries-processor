# 0.7.21

Adds remaining derivation methods to complete the CRNS (cosmic-ray neutron sensor) soil moisture chain - SWE, sigma SWE,
effective depth and D86 - along with SWE and sigma SWE for the below-ground SnowFox sensor, and a Soil Moisture Index
(SMI) derivation. Site annotations that vary over time (e.g. wilting point, field capacity, saturation) can now be
joined onto a calculation the same way time-varying deployment attributes already are.

Also improves the metrics reported to Pushgateway, so failures and dataset counts can be broken down by site.

### New features

- **CRNS SWE**: `SnowWaterEquivalence` calculates snow water equivalent for the above-ground CRNS sensor.
- **CRNS sigma SWE**: `SigmaSnowWaterEquivalence` calculates the uncertainty on SWE, following the standard method
  with reference equations from Wallbank et al. (2020).
- **CRNS effective depth**: `calculate_eff_depth` derivation method.
- **CRNS D86**: `calculate_d86` calculates the depth to which 86% of the detected cosmic ray neutrons had contact
  with soil constituents.
- **SnowFox SWE and sigma SWE**: `SnowWaterEquivalenceSnowfox` and `SigmaSnowWaterEquivalenceSnowfox` calculate SWE
  and its uncertainty for the below-ground (buried/SnowFox) COSMOS sensor, alongside the existing above-ground
  methods.
- **Soil Moisture Index**: `SoilMoistureIndex` normalises `cosmos_vwc` against the site's wilting point, field
  capacity and saturation annotations.
- **Time-varying site annotations**: a data processing config can reference a site annotation that changes over
  time (e.g. `wilting_point`, `field_capacity`, `saturation`) via the existing `argument.annotation` mechanism, and
  have it joined onto the calculation as a per-row value, the same way time-varying deployment attributes (e.g. wind
  height) already work.
- **Per-site Pushgateway metrics**: each processor job now pushes its metrics under its own site label, instead of
  every pod overwriting the same job. Counter metrics also carry a dataset label, and a new gauge reports the total
  number of failed datasets per site.

### Bug fixes

- **SnowFox column naming**: the below-ground SnowFox sensor reuses the CRNS `CorrectCounts` and
  `GetSnowEstimatedCounts` derivation methods, but its input timeseries are named differently (e.g. `cts_snowfox` vs
  `cts_mod`, `cts_smo_snowfox` vs `cts_smo_crns`). `DerivationMethod.run` no longer filters `config.params` down to
  a method's declared input names before building its `tf_map`; it now collects every TimeFrame present in
  `config.params`, and a new `_get_crns_column` helper resolves which of the CRNS/SnowFox column name variants is
  present. This is a temporary workaround pending a metadata-driven fix.

### Testing

- Added unit tests for each new derivation method, including real-data tests for the sigma SWE calculation.
- Added an end-to-end test case covering the P1D VWC variables, including SnowFox.
- Added unit tests covering the time-varying annotation join and the SMI boundary values.
