# 0.8.5

- Fixes bug where values removed by QC were not getting the `removed` core flag.
- The solar zenith and albedo derivations work with networks that name their shortwave radiation columns differently

### New features

- **Shortwave radiation column names**: `SolarZenith` and `Albedo` accept either `swin`/`swout` or
  `r_sw_in_avg`/`r_sw_out_avg` as their input columns, so networks with different naming can use the same methods. A
  `KeyError` is raised if the columns can't be matched to exactly one name.

### Bug fixes

- **`removed` core flag after QC**: when `QCPipeline` removes data that failed QC checks, it now runs the core flag
  updater, so the removed values get the `removed` core flag.
- **`corrected` core flag kept on removed values**: `update_quality_control_core_flags` no longer clears the
  `corrected` flag when it adds `removed`, so a value that was corrected and then removed keeps both flags.

### Dependencies

- `time-stream` updated from 1.2.1 to 2.0.0. `Period` has moved out of `time-stream` into the new `isoperiod`
  package, which is added as a dependency.
