# 0.7.29

Adds an absolute correction method and extends the longwave radiation correction to support the NR01 sensor's own
temperature reading as an alternative to air temperature, using the timeseries unit metadata to convert between
degrees Celsius and Kelvin correctly.

### New features

- **Absolute correction**: `Absolute` applies an absolute value correction to a column over a given date range.
- **LW correction temperature source**: `LWCorrection` can now source its temperature input from either air
  temperature (`ta`) or the NR01 sensor's own temperature (`t_nr_avg`), and reads the unit metadata on that
  temperature TimeFrame (`degc` or `kel`) to decide whether a Celsius-to-Kelvin conversion is needed, rather than
  assuming Celsius.
