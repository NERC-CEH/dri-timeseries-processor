# 0.7.1

Adds a guard for handling any processed dataset registered in the metadata that doesn't have any associated data
processing configurations.

### Bug fixes

- **Processed datasets with no processing configs are skipped**: `_collect_load_containers` leaves these out of the
  load, logs which dataset was skipped, and marks it as failed so the run still reports it at the end.

### Testing

- Added unit tests covering the skip, the load-only exemption, and the data router not being queried.
