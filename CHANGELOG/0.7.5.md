# 0.7.5

Each processor job now reports its metrics to the Pushgateway under its own job name, instead of all jobs
sharing the same hardcoded name.

### New features

- **Configurable Pushgateway job name**: `pushgateway_job_name` is a new required configuration value, used
  in place of the hardcoded `"timeseries-processor"` string when reporting metrics. This lets metrics from
  separate processor jobs be told apart in the Pushgateway.

### Bug fixes

- **Deployment start date can be missing**: `DeploymentItem.start_date` is now optional, since an existing
  site can have a deployment with an unknown start date.

### Testing

- Added unit tests covering the new `pushgateway_job_name` configuration value and the empty-value error.
