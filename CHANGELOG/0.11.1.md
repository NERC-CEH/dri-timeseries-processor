# 0.11.1

Bug fix: processed datasets whose column name differs from the raw dataset they load from.

### Bug fixes

- **Column names in `load`**: the `load` step looked up the raw data using the processed dataset's column name, so it
  raised a `ColumnNotFoundError` when the two names differed (e.g. `PLS500_Lvl_cm_Avg` processed from
  `PLS500_Lvl_m_Avg`). It now reads the dependency's own `source_column` and renames it to the processed dataset's
  column name.
- **No column name to load into**: `load` now raises a clear `ValueError` if the processed dataset has no
  `source_column`, instead of failing inside `select`.
